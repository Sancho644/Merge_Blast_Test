# Merge Blast: Overload

Вертикальный 2D Neon Arcade прототип на стыке Ball Blast и 2048. Unity 6 / Android. Автоматическая стрельба, физическое объединение шаров, Overload, реактивные бомбы и прокачка рикошетов.

**Статус:** подготовка завершена на уровне спецификации и подбора ассетов; Unity-проект и APK ещё не созданы. Репозиторий не создан этим комплектом. Бюджет ТЗ — не более 8 часов чистой работы.

## Как начать
1. Создать MergeBlast в Unity Hub: Unity 6 LTS, Universal 2D, Android Build Support. Зафиксировать точную версию редактора.
2. Распаковать этот комплект в корень проекта: README.md, AGENTS.md и docs/. Не заменять существующие пользовательские файлы без сверки.
3. Скачать/импортировать только разрешённые ассеты по manifest. CraftPix — отдельный лицензионный блокер, см. ASSET_LIST. Архивы ассетов в этом комплекте отсутствуют.
4. Открыть локальную папку в Codex, начать с P0 и передать ему AGENTS.md. Настроить Git локально; публикация после проверки лицензий.
5. После реализации открыть Assets/_Project/Scenes/Main.unity, Play в редакторе; Android Build Profiles → Build APK. Эти шаги описывают предполагаемую структуру, пока сцена не создана.

## Управление
Свайп по горизонтали — двигать пушку, стрельба автоматическая, тап по бомбе — активировать до окончания таймера. 75 секунд / 3 сердца. Монеты тратятся между боями, уровень 1–10, рикошеты доступны на 3/6/9.

## Сдача
APK (WebGL-ссылка при невозможности Android), репозиторий/архив проекта, дизайн-записка до страницы, 2–3 строки о фактическом времени и ассетах/AI. Не заявлять о выполнении тестов и сборке до фактической проверки.
