# Merge Blast: Overload

Вертикальный 2D Neon Arcade прототип на стыке Ball Blast и 2048. Unity 6 / Android. Автоматическая стрельба, физическое объединение шаров, Overload, реактивные бомбы и прокачка рикошетов.

**Статус:** P0 принят. Подготовлены сцена Main, настройки Android и стартовые конфиги. Игровые механики и сборка APK запланированы на следующие этапы. Бюджет ТЗ — до 8 часов чистой работы.

## Как начать

1. Открыть checkout в Unity Hub в редакторе `6000.6.7f1` с Android Build Support, SDK/NDK и OpenJDK.
2. Открыть `Assets/_Project/Scenes/Main.unity` и запустить Play Mode. Для портретного просмотра выбрать 1080×1920 или 1080×2400 в Game View.
3. Хранить локальные архивы и распакованные исходники в `_SourceAssets/` в корне проекта. Папка исключена из Git и находится за пределами импорта Unity. Для работы сцены P0 она не требуется. Правила выбора и импорта файлов описаны в [Asset List](docs/ASSET_LIST.md).

## Управление
Свайп по горизонтали — двигать пушку, стрельба автоматическая, тап по бомбе — активировать до окончания таймера. 75 секунд / 3 сердца. Монеты тратятся между боями, уровень 1–10, рикошеты доступны на 3/6/9.

## Сдача
APK (WebGL-ссылка при невозможности Android), репозиторий/архив проекта, дизайн-записка до страницы, 2–3 строки о фактическом времени и ассетах/AI. Не заявлять о выполнении тестов и сборке до фактической проверки.
