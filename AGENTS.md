# AGENTS.md — инструкции для Codex

## Цель
Реализовать Merge Blast: Overload как компактное тестовое задание Unity 6. Ограничение всего задания — 8 часов чистой работы. Gameplay feel, UI feel, обоснованные решения важнее архитектуры и объёма контента.

## Перед работой
Прочитать `docs/GDD.md`, `docs/TDD.md`, `docs/TASKS.md`, `docs/ART_GUIDE.md`, `docs/AUDIO_GUIDE.md`, `docs/ASSET_LIST.md`. GDD определяет игровые правила, TDD — предлагаемый способ реализации, TASKS — порядок и приёмку. Если пользователь позднее дал другое правило, оно имеет приоритет; обновить документы, явно указать изменение. Не придумывать новые механики без запроса. При недостающих значениях использовать стартовые конфиги и сообщить допущение.

## Рабочий процесс
1. Проверить локальный проект, версию Unity, Git status и существующие изменения. Не удалять и не перезаписывать изменения пользователя.
2. Работать по одному P-этапу, минимальным объёмом кода, с понятными сериализованными ссылками. Не переходить к следующему этапу, пока не сообщены итоги текущего.
3. Проверить компиляцию/Play Mode, если есть доступ к Unity. Использовать editor scripts для повторяемой настройки сцены при необходимости. Не выдавать статическую проверку за запуск Unity. Не создавать сложный фреймворк тестов; короткий smoke test и ручные проверки важнее.
4. Обновить TASKS.md по факту. Отчёт: сделано, файлы, проверки с реальным результатом, незавершённое, блокеры и дальнейший шаг. Не заявлять, что APK собран, если не собран.
5. Не публиковать, не создавать PR/commit/push или изменять внешние ресурсы без явного запроса. Не включать секреты и ограниченные ассеты. Сохранять .meta разрешённых файлов.

## Код
Обычные MonoBehaviour, сериализованные поля, C# events, ScriptableObject configs. PascalCase для типов/методов, `_camelCase` для приватных полей, понятные имена; явная ответственность. Не подключать ECS, DI, глобальный EventBus, Spine, networking, ads, persistence. Не добавлять зависимости без необходимости. Не менять физический collider ради анимации. Не мутировать ScriptableObject runtime. Не начислять монеты из UI. Для столкновений снаряда — sweep/CircleCast, не смешивать с Rigidbody2D collision logic. Merge и Bomb — атомарные переходы состояния. При новом бою сбрасывать runtime, события, корутины, timeScale, fixedDeltaTime.

## Арт и лицензии
Использовать manifest; не скачивать новые паки без причины. CraftPix локально для проверки; разрешение на передачу исходников не подтверждено и ТЗ требует открытую лицензию. Не включать его в сдаваемый проект до согласования либо замены. Даже производные изображения не считать автоматически свободными. При отсутствии ассета временно использовать простую геометрию, сообщить. Никаких непроверенных ассетов в публичном Git. Не добавлять шрифты без OFL и необходимых notices. Не использовать AI-generated branding из паков, не относящийся к лицензии. Указать применение AI в итоговой записке только по факту.

## Definition of done
Рабочий Android APK (или согласованная WebGL альтернатива), 4 экрана, 75-секундная волна, Merge/Overload, Bomb, Ricochet 3/6/9, visible reward, прогресс и быстрый повтор, проверка на устройстве, исходники с корректными лицензиями, дизайн-записка до страницы, честное фактическое время и инструменты. Не раздувать scope ради красивого отчёта.
