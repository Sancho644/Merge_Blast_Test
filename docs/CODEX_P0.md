# Первый промпт для Codex — P0 Project Setup

Работаем над Unity 6 проектом MergeBlast, тестовым прототипом на 8 часов. Прочитай AGENTS.md и все документы в docs/. Выполни только P0 из TASKS.md, не переходи к P1.

Сначала проверь фактическую версию Unity, структуру проекта, Packages, ProjectSettings и git status. Не перезаписывай пользовательские изменения. Если Unity-проект ещё не создан, сообщи точный блокер, не генерируй фиктивные бинарные файлы. Настрой структуру Assets/_Project, Main.unity, URP 2D, ортографическую камеру, portrait 1080×1920, Canvas/SafeArea, EventSystem под Input System, арены и physics layers. Подготовь минимальные конфиги с параметрами GDD. Не реализуй полную игровую логику. Если потребуется автоматизация сцены, используй повторяемый Editor script без дублирования объектов.

Проверь импорт доступных разрешённых ассетов; не включай CraftPix в коммиты и сдаваемые исходники до разрешения лицензии. При отсутствии графики используй временные placeholders. Не устанавливай лишние зависимости. Подготовь .gitignore для Unity и локальных ограниченных ассетов.

Приёмка: Main открывается, Play Mode без ошибок при доступном редакторе, арена и Canvas корректны, слои заданы, Android доступен либо указан реальный блокер. Обнови P0 в TASKS.md только по фактическим результатам. В отчёте перечисли изменённые файлы, проверки, оставшиеся вопросы, потраченное время (если оно измерено) и статус. Не коммить и не публикуй без команды пользователя.
