## P1 — Core Gameplay (65)
- [ ] Пушка: mouse/touch relative drag, clamp, автострельба, hitbox, 3 жизни/invuln.
- [ ] Ball: спавн, движение, bounce, number, HP, уничтожение, начисление монет.
- [ ] Projectile: CircleCast без рикошетов на первом этапе; корректные контакты и lifetime.
- [ ] Приёмка: удержание, отпускание, края, выстрелы без ввода, попадания и разрушение, нет двойного урона/монет.

## P2 — Merge & Overload (45)
- [ ] Резервирование пары, суммирование HP, спавн нового шара и cooldown.
- [ ] 16+16 → 32 explosion, радиус/урон/награда, первый контролируемый спавн.
- [ ] Приёмка: 4(3 HP)+4(2 HP)=8(5 HP); разный номинал не сливается; тройной контакт не дублирует; 32 не остаётся; награда за удалённых Merge-шаров отсутствует.

## P3 — Bomb & Ricochet (60)
- [ ] Случайный спавн, один активный объект, таймер 5 сек, радиальный UI; тап/таймаут; свайп/тап разграничены.
- [ ] Реализовать отражение и budget дистанции, walls/floor/ceiling, лимит, игнорирование Bomb/Cannon/Projectile.
- [ ] Приёмка: успешный тап наносит урон обычным шарам, не двигает пушку; пропуск ровно −1 сердце; нет штрафа при завершении боя. Тап/таймаут не оба. 0 bounce — исчезновение на 1-м контакте; 3 — на 4-м. Урон при последнем контакте, скорость неизменна, отражение от уничтоженного шара, углы без застреваний.

## P4 — Battle Flow & Progression (45)
- [ ] Таймер 75 сек, волна, cap 16; Victory/Defeat; награда один раз; очистка.
- [ ] Progression 10 уровней, кошелёк, 3 последовательные покупки рикошетов, визуальная модель.
- [ ] Приёмка: нет повторного начисления при Continue/Restart; покупка при недостатке денег/lock/max не меняет данные; 3/6/9 открывают покупку, не выдают автоматически; прогресс сохраняется между боями; три рестарта без старых объектов/корутин.

## P5 — UI (85)
- [ ] Start, HUD, Results, Meta по ART_GUIDE.
- [ ] Анимации кнопок, открытие экранов, монеты и счётчик; visible next stats, blocked/max states.
- [ ] Приёмка: полный цикл и быстрый рестарт за пару тапов, safe area 9:16/9:20, тапы не проходят сквозь UI, числа и сердца читаются, награда визуально переносится.

## P6 — Gameplay/UI Feel (75)
- [ ] CraftPix T1–10 (при разрешении), стрелковые кадры, HP/таймер бомбы, trails, feedback попаданий.
- [ ] Merge, Overload, Bomb, Ricochet VFX и SFX; music transitions, AudioMixer, ограничение частых звуков.
- [ ] Приёмка: видимый Overload в первой сессии по возможности, читаемая бомба, отчётливые рикошеты, заметная покупка; Slow Motion восстанавливает timeScale и fixedDeltaTime; нет аудиоклиппинга.

## P7 — QA / Build / Delivery (80)
- [ ] Реальный Android playtest: первый бой, поражение, победа, повтор, первый рикошет, несколько bomb events; проверка уровня 10 через временный editor/debug override (не оставить в релизном UI).
- [ ] Баланс: записать длительность, coins/бой, момент Overload, частоту bomb missed, покупку за 1–2 удачных боя. Если не работает, изменить конфиги и записать причину.
- [ ] Проверить FPS, UI, громкость на телефоне, отсутствие ошибок, restarts. WebGL — запасной вариант при невозможности APK.
- [ ] Проверить лицензии, THIRD_PARTY_NOTICES.md, подготовить репозиторий/архив без запрещённых файлов, инструкцию импорта при согласовании.
- [ ] Собрать APK, установить и запустить; записать фактический результат и ограничения. Обновить DESIGN_NOTE.md по реально опробованным решениям, не более страницы. Фактическое время, готовые ассеты и AI-инструменты указать в 2–3 строках.

## Минимальный QA checklist
| Сценарий | Ожидание |
|---|---|
| Start → Battle → Results → Meta → Battle | Работает без reload и зависаний |
| Victory/Defeat | Timer/HP корректны, одна награда |
| Merge triple contact | Только одна пара, без дубликатов |
| Overload | Радиус, 16 damage, +64, без урона игроку |
| Bomb tap/timeout/end | Только один исход, корректный HP/reward |
| Drag vs tap | Нет прыжка пушки при тапе |
| Ricochet 0/1/2/3 | 1/2/3/4 контакта до исчезновения, скорость сохранена |
| Upgrade locks & funds | Нет расхода при отказе, смена Tn при покупке |
| Restart | Нет старых пуль, бомб, tweens, timeScale восстановлен |
| Mobile | Safe area, touch, FPS, звук, установка APK |
