# Art Guide — Neon Arcade

## 1. Направление
Тёмно-синяя арена, яркие энергетические шары, металлические пушки CraftPix, неоновые кнопки Late Night и технологичные панели Wenrexa. Цель: контраст, читаемость с телефона, согласованность графики. Не искать новые наборы без конкретной причины. Вариант Neon Spheres — рабочий выбор для сборки; утверждение окончательного вида после Visual Preview. Использование CraftPix условно до разрешения вопроса лицензии (ASSET_LIST.md).

## 2. Игровая графика
- Пушка: T1–T10, одноствольные модели с уже нанесённым уровнем. 15 кадров на уровень, целый спрайт. `Tn-Shoot_00.png` как кандидат idle (визуально проверить первый кадр). Анимировать существующими кадрами, без Spine; фактический момент выстрела определяется кодом. Сохранять единый pivot и размер, не менять хитбокс между уровнями. Проверить позицию ShootPoint по всем моделям.
- Пуля: Projectile1 (оранжевая, 0), Projectile2 (голубая, 1), Projectile3 (зелёная, 2), фиолетовая производная от нейтрального/голубого спрайта (3). Простое умножение синего RGB на фиолетовый может не дать нужного цвета: использовать grayscale/white mask или собственный HDR материал. След всё ярче, но не закрывает шары.
- Шары: Colored Spheres по номиналам 2/4/8/16/32 — sphere-13/23/02/12/22.png. Отдельное свечение Kenney circle_03, HP ring, TMP number поверх; номер читается независимо от цвета. 32 — только VFX Overload. Цветное свечение не входит в радиус коллайдера. Пульсация, flash, punch scale только на Visual.
- Bomb: 6 кадров Red Animated Orb, тёмная центральная подложка для номера при необходимости, радиальный таймер внутри/по контуру, красная пульсация. Отличие не только цветом: металлическая рамка, таймер, предупреждение. SVG bomb — резерв, не импортировать без необходимости.
- Shield Ball: сохраняет номер и кольцо HP своего номинала. Сегментированная голубая броня снаружи кольца отличает его по форме. Сегменты могут вращаться, номер и кольцо HP остаются неподвижными.
- Energy Shield: полупрозрачное поле вокруг пушки, контур `#00D9FF` и акценты `#B5FAFF`. Два видимых сегмента соответствуют двум зарядам. Контур и сегменты остаются за пределами хитбокса.
- Фон: простой тёмный градиент, слабая сетка Wenrexa Grid.png, границы арены, без детализации. UI должен выделяться поверх поля.

## 3. UI
Основные действия cyan, покупки green, рикошет purple. Disabled визуально отличается и не реагирует как активный. Не использовать встроенные надписи ассета: пустые кнопки Late Night + TMP. Рекомендуемые панели Wenrexa MainPanel02/03, TitlePanel02, Button11 (проверить пригодность для disabled). Не растягивать декоративные панели до деформации углов; 9-slice там, где текстура позволяет. Glow baked in — не усиливать через Bloom на Canvas. Шрифты Bebas Neue (логотип и заголовки), Teko (цифры/характеристики); оба ещё надо скачать и проверить наличие необходимых символов. UI на английском для прототипа. Текст читаемый, без чрезмерно узких букв; для мелких пояснений допустим TMP default как временная замена.

| Экран | Композиция и приоритет |
|---|---|
| Start | Логотип вверху, кошелёк, крупная пушка, PLAY внизу; короткий старт |
| Battle HUD | Монеты слева, таймер в центре, сердца справа; полоска времени под HUD; поле не перекрыто |
| Results | Заголовок Victory/Defeat, крупная монета/сумма, разбивка, Continue, вторичный Restart |
| Meta | Валюта, крупный Tn, уровень 1–10, Damage/Fire Rate/Bounces, Cannon Upgrade, Ricochet Upgrade, Play Again |

Late Night bar-0 — фон индикатора, а не готовая динамическая заливка. Для непрерывного прогресса использовать отдельный однотонный/градиентный fill (Image Filled) в маске; не переключать только 5 дискретных картинок. В Kenney Game Icons нет подходящей иконки сердца в проверенной папке White/2x — нарисовать простую форму/временный символ, не искать ещё один пак. Не использовать эмодзи как готовые игровые спрайты. Safe Area на мобильном, минимум 44–48 dp touch targets, кликабельные области не пересекаются.

## 4. Feedback
| Событие | Визуальный отклик |
|---|---|
| Shoot | Покадровая отдача и Shoot Fx, лёгкий flash |
| Hit | White flash, короткий punch scale, spark |
| Destroy | При уничтожении снарядом — яркая вспышка, 10 частиц цвета номинала, расширяющееся кольцо и всплывающая надпись с наградой. Предварительный эффект длится 0,35 сек |
| Merge | Сжатие/рост нового шара, кольцо, цветные искры |
| Overload | Gold shockwave, крупная надпись, короткое slow motion/shake |
| Bomb spawn / tick | Красный контур, таймер, растущая пульсация |
| Bomb success | Золотая/красная волна по полю, эффект на пострадавших шарах |
| Bomb fail / damage | Короткий красный flash, исчезновение сердца, shake |
| Ricochet | Маленькая искра в точке контакта, trail |
| Shield Ball / ShieldAcquire | Распад броневых сегментов, перелёт энергии к пушке и разворачивание поля |
| ShieldHit | Локальная вспышка в точке контакта и исчезновение одного активного сегмента |
| ShieldBreak | Короткая вспышка и распад контура после последнего заряда |
| Victory | Reward burst / конфетти, count-up |
| Purchase | Punch, зелёная подсветка новых значений, смена Tn |
| Buttons | Scale 1→0.92→1, 0.1–0.2s; отключённые не анимируются как купленные |
| Screen enter | Fade + Back Out, 0.2–0.35s |

Тайминги — предложения для первого прохода. Монеты летают в HUD во время боя и в кошелёк на Results/Meta; отображение следует реальным начислениям, не блокировать продолжение длинной анимацией. Объединять множество монет в небольшое число частиц. Не трясти UI вместе с камерой.

## 5. Импорт и QA
Sprite Single, alpha transparency, Bilinear, Mipmaps Off, Read/Write Off, Full Rect. Шары max 256, бомба/VFX/пушки max 512, UI по размеру оригинала (до 1024/2048 при необходимости). Единый PPU по группе, реальный мировой радиус по конфигу, а не размеру PNG. На Android сжимаем спрайты только после проверки качества прозрачных краёв (ASTC/ETC2 по поддержке устройства). URP Bloom на world-space HDR emissive/additive материалах, не на обычном SDR tint; если эффект не работает, оставить baked glow. Ограничить число частиц и размеры trail, оценить FPS. Сначала собрать визуальный preview в Main или временной сцене, не добавлять лишнюю сцену в билд. Сверить арт при реальном размере телефона.
